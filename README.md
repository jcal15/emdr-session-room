# EMDR Session Room

Bilateral stimulation (light + sound) for remote EMDR sessions. The therapist controls the session from their device; the client follows on theirs (works on iPhone). No account needed.

Open the page, choose a role, and share the 6-character session code. Live sync uses free public MQTT relays and carries only the settings, never personal details.

Not a substitute for therapy. Use with a qualified EMDR therapist.
